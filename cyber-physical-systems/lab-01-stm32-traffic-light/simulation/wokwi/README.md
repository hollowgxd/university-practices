# Wokwi-проверка логики

Wokwi сейчас поддерживает STM32F103C8/Blue Pill, но не STM32F107VCT6. Поэтому
этот каталог является **приближённой симуляцией GPIO и кнопки**, а не доказательством
работы целевого микроконтроллера. Оба чипа относятся к STM32F1/Cortex-M3 и работают
на 72 МГц, но распиновку и периферийные особенности STM32F107 нужно проверять на
реальной плате.

Файл `diagram.json` можно открыть в Wokwi for VS Code. Для запуска нужен собранный
ELF в `build/traffic-light.elf`; Wokwi сам проект не компилирует. Wokwi CLI требует
токен пользователя, поэтому токен в репозиторий не добавляется. Кнопка имеет
клавишу `B`.

Основная аппаратная конфигурация остаётся в `project/TrafficLight.ioc` для
STM32F107VCT6. Wokwi используется только как визуальная проверка схемы и GPIO.
У Blue Pill в Wokwi нет отдельного выведенного `B2`, поэтому симуляционный
`B6` соответствует целевому `PB2`; это ещё одна причина не выдавать surrogate за
точную проверку распиновки STM32F107.
