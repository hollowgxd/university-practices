# Матрица приёмки

| Сценарий | Ожидание | Локальный результат |
|---|---|---|
| `GET /health` | HTTP 200, `status=ok` | Не запускался: на хосте нет Docker |
| `GET /last` | HTTP 200, последняя ISS-запись или `message` | Не запускался: на хосте нет Docker |
| `GET /iss/trend` | HTTP 200, расчёт дистанции между двумя точками | Не запускался: на хосте нет Docker |
| `GET /osdr/sync` | Upsert по `dataset_id` | Не запускался: внешний стенд и Docker недоступны |
| `GET /space/summary` | HTTP 200, кэшированная витрина | Не запускался: на хосте нет Docker |
| Rust unit tests | Haversine и RFC3339 | `cargo test` запускается после `cargo check` |

Ограничение честно зафиксировано: локальный хост не содержит Docker CLI/daemon,
поэтому интеграционные проверки Compose не выдаются за выполненные.
Подобно нет локального PHP CLI, поэтому PHP-lint отмечен как невыполненный; код проверяется в PHP-образе.
